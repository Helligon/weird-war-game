# Unit tags and Strange Brigades

## Summary
Each Section type has a **class** (what it does) and, as proposed, an **origin** (Mundane or Strange). Creatures can belong to any class, and a Brigade made up mainly of creatures is a **Strange Brigade**.

## Rules
### Class tag
- **TAG-001** (`decided`): Each Section type MUST have a class. Known classes: Infantry, Heavy, Artillery, Support. Others MAY be added.
- **TAG-002** (`decided`): Creatures and fantastical beings MUST be able to have any class (Infantry, Heavy, Artillery, etc.).

### Origin tag
- **TAG-003** (`decided`): Creatures MAY act as supplementary Sections in an ordinary Brigade.
- **TAG-004** (`decided`): A Brigade with 4 or more Strange Sections MUST count as a **Strange Brigade** (BRG-030).
- **TAG-005** (`proposed`): Each Section type SHOULD have an origin tag: **Mundane** or **Strange**.
- **TAG-006** (`proposed`): A Brigade SHOULD earn at most one class bonus and one origin bonus (e.g. 3 vampire Sections → Infantry bonus + Strange bonus).
- **TAG-007** (`proposed`): Strange bonus ideas: immune to morale penalties, a fear aura, or night-fighting bonuses.
- **TAG-009** (`decided`): Some Strange Sections MUST be **undead** (Thralls/Ghouls, Vampires), with the special supply rules in [[supply#Undead]]. Detailed unit designs are to come from Alex.

### Trait tags
- **TAG-012** (`decided`): Sections with the Heavy or Artillery class count as **heavy weaponry** against HQs and FOBs (MAP-042).
- **TAG-013** (`decided`): Faction-specific Sections MUST use one of the existing classes (Infantry, Heavy, Artillery, Support), plus the Strange tag where relevant. They MAY also carry nation or Faction tags (FAC-009).
- **TAG-010** (`decided`): A **Slow** tag MUST exist. Slow Sections have a hexes-per-turn movement cap (SUP-024). Thralls/Ghouls have it; Vampires do not (SUP-022).
- **TAG-008** (`proposed`): Strange downsides: Medics cannot heal Strange Units (only occultists or similar can); possibly unreliable when Overextended (a creature may go rogue). ~~Upkeep paid in CP~~: rejected, see TAG-011.
- **TAG-011** (`decided`): Strange Sections MUST spend SP like every other Section. CP is reserved for Cards.
